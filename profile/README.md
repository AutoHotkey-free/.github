## 🧠 Overview

AutoHotkey (AHK) is a free and open-source custom scripting language for Microsoft Windows, primarily designed to provide easy keyboard shortcuts, fast macro-creation, and software automation, to allow users of most computer skill levels to automate repetitive tasks in any Windows application. It can easily extend or modify user interfaces. Free keyboard macro program. It is developed by Chris Mallett, Steve Gray. The product family is positioned as a scripting language automation gui utility toolset for Windows workflows.

AutoHotkey works as a Windows utility on Windows 10 and Windows 11 and is installed from a single package.
